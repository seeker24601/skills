# Archive

Use when asked to preserve notes, a conversation, decisions, or source material.

1. Establish the authorized material and requested destination. Read the area's conventions and search for an existing subject owner. Preserve actual agreements separately from suggestions.
2. Load `record-keeping` to prepare and save the record. Keep attribution, relevant dates, constraints, uncertainty, and useful history. Preserve raw evidence whole; a concise synthesis may link to it without replacing it.
3. For an eligible synthesized or LLM-facing note becoming repetitive, load `prompt-token-trimmer`. Respect its exemptions and the user's edit authority. Do not shorten records merely to hit an arbitrary length target.
4. Link the saved record from its nearest useful index. Read it back and verify affected links using the tool contract in `AGENTS.md`.
5. If filing exposes duplicates or broken organization, use `workflows/curate.md` for only the upkeep within this request. Broader restructuring needs its own scope.

Report the saved location and any incomplete operation briefly. Never claim a save without a successful write and verification.
